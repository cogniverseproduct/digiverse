# DigiVerse

### One Platform. Multiple Communities. Limitless Digital Experiences.

**DigiVerse** is a multi-engine SaaS platform designed to help organizations, clubs, cultural associations, sports communities, NGOs, and event organizers build and manage their digital presence through a centralized platform.

DigiVerse aims to simplify website creation and digital management through specialized website engines, reusable templates, centralized administration, and AI-assisted website generation.

---

## 🚀 About DigiVerse

Managing a community or organization online often requires multiple tools, technical knowledge, and considerable effort.

DigiVerse brings these experiences together in one platform.

It provides specialized website creation engines for different organizational needs, allowing customers to create customized digital experiences while the product owner manages the overall platform centrally.

## ✨ Key Features

- **Multi-Engine Architecture** – Specialized website creation engines for different industries and communities.
- **AI-Assisted Website Generation** – Generate customized website experiences using organizational information and media.
- **Template-Based Website Creation** – Choose from purpose-oriented website templates.
- **Centralized Administration** – Manage platform operations through a centralized Super Admin dashboard.
- **Organization Management** – Support clubs, associations, committees, NGOs, sports organizations, and event organizers.
- **Digital Content Management** – Manage announcements, events, schedules, galleries, and organizational information.
- **Media Integration** – Designed to support Google Drive media ingestion and YouTube content integration.
- **Responsive Design** – Build digital experiences suitable for desktop, tablet, and mobile devices.
- **Independent Website Deployment** – Designed to support independently deployable customer websites.

## 🧩 Website Engines

DigiVerse is designed around specialized website engines:

| Engine | Purpose |
|---|---|
| Sports Website Engine | Sports clubs, tournaments, and sports academies |
| Cultural Website Engine | Cultural associations and Puja committees |
| Event Website Engine | Conferences, festivals, exhibitions, and events |
| Social & NGO Website Engine | NGOs, foundations, trusts, and charitable organizations |
| Portfolio Website Engine | Personal and professional portfolios |

## ⚙️ Getting Started

### Prerequisites

- Node.js (Node.js 22 recommended)
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/cogniverseproduct/digiverse.git
```

### 2. Navigate to the Project

```bash
cd DigiVerse
```

### 3. Install Frontend Dependencies

```bash
cd digiverse-client
npm install
```

### 4. Start the Frontend

```bash
npm run dev
```

### 5. Install Backend Dependencies

Open another terminal:

```bash
cd digiverse-server
npm install
```

### 6. Start the Backend

```bash
npm run dev
```

**Note:** Configure the required environment variables before starting the application. Refer to the project's environment configuration and backend setup.

## 🔐 Security

DigiVerse is designed with security considerations including:

- JWT-based authentication
- Password hashing
- Role-based access control
- Secure server-side configuration
- Protected API endpoints
- Secure handling of integration credentials

Never commit real API keys, passwords, JWT secrets, or private credentials to a public repository.
